# Zamrożone indeksy tematyczne Wikisłownika

Autorzy: współtwórcy polskiego Wikisłownika. Tekst indeksów na licencji
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Każdy tytuł, identyfikator wersji, data, URL tej wersji, historia autorów,
rozmiar i SHA-256 znajdują się w `intake-lock.json`. Pliki `.wikitext`
zachowują pobraną treść wersji bez zmian; CI nie odwołuje się do zmiennej strony.

Przetworzenie: pojedyncze małoliterowe cele linków → dokładnie poświadczone
zwykłe lematy SGJP → poświadczone odmiany → filtrowanie częstości wordfreq.
Nie kopiujemy definicji ani nie dopisujemy ręcznie słów/opisów. Pochodny wybór
tematyczny również CC BY-SA 4.0; licencje istniejących zasobów pozostają.
Dowody i decyzje, w tym braki SGJP, pozostają w osobnych audytach JSONL.

To warstwa selekcji rodzin, nie słownik rozróżniający wszystkie znaczenia.
Homograf może mieć w SGJP kilka zwykłych lematów; źródłowe odczytania są
zachowane, ale samo wystąpienie w indeksie nie nadaje im ręcznych opisów znaczeń.
